# 微信小程序源码

这是速成车关注指数计算器的原生微信小程序版本。无需后端、登录或网络请求。输入在设备上计算，手动保存的最多 5 条记录只写入微信本机存储。

## 本地导入

1. 安装微信开发者工具。
2. 选择“导入项目”，目录选本 README 所在的 `calculator/wechat` 文件夹。
3. 本源码使用 `touristappid` 供游客模式本地测试；编译类型为“小程序”。
4. 编译后在模拟器中打开首页。试算空输入、虚拟示例，并用可用的测试 AppID 进行真机预览。

`touristappid` 不是可以发布的 AppID。正式发布需要注册自己的小程序账号，替换 `project.config.json` 的 `appid`，在微信开发者工具上传，并完成微信平台要求的资料、审核及发布。游客模式的预览和分享能力可能受平台限制。源码尚未通过微信平台审核，也未声称已上线。

## 输入与结果

- 默认全部未知，月数和 SKU 为空。未知不会当作 0 分。
- 五个维度是研发周期、全球化、正式召回历史、用工保障及 SKU。用工拆成五险一金与外包 / 派遣，两小项取较高分。
- 同一车型的“立项到上市”月数不能由草图到量产、收购到交付等不同起止事件替代。
- “没有正式召回历史”是用户有依据的确认；仅仅查不到记录，应保持“尚不了解 / 尚未查到记录”。
- 结果展示 0–100 的综合指数或区间、已确定权重、每项加权贡献及最大资料缺口。区间已经收敛也可能仍有字段未知。
- “已确定计分权重”只统计按用户输入能够确定贡献的权重，不代表原始字段完整或输入来源已审核。“仍未知的输入”另行列出所有原始未知字段，包括用工计分已固定时仍未知的缴费情况。这里不收集或认证证据。
- 指数表达这套选购偏好的关注程度。没有经过真实标签样本的概率校准，不展示事故概率或“速成车概率”。
- 输入确认外包 / 派遣、未解决欠缴、仅中国市场销售、无召回历史、召回责任未履行或 SKU 过多时，按核心规则展示独立选购偏好提示。这些不是违法或车辆缺陷的自动判断。

## 本机记录与分享

“保存到本机记录”会保留最多 5 条输入，重复输入替换旧记录。载入时按当前规则重新计算。“清空输入”不删除记录；“删除记录”只删除本机记录。没有云端存储。

“分享给朋友”只分享固定工具入口 `/pages/index/index`，不携带输入、指数或本机记录。程序不请求通讯录、位置、手机号或用户账号，也没有统计分析 SDK。

页面底部展示 GitHub 仓库入口。证据贡献需用户自行访问仓库提交原始链接、适用范围与时间，由维护者审核；小程序不会自动上传或把填写内容转为公开事实。

## 规则与维护

`utils/scoring.js` 是 `../shared/scoring.js` 的同步副本。修改计分规则时，应先更新共享内核，再同步此文件；无需重新编写微信适配逻辑。UI 中的解释与选项应跟随共享内核更新。

本页面使用 `Page`、WXML、WXSS 及本地存储 API，无第三方运行时。游客 AppID 配置和空页面路由可以在开发者工具直接导入。

## 手动验收

1. 空输入计算得到 0–100，已确定权重 0；最大缺口是研发周期。
2. 虚拟示例：24 个月、同代车型已在多个市场销售、有召回、4 个 SKU，五险一金与外包均未知，显示约 29.7–44.7 / 100，已确定计分权重 85%。示例横幅说明不对应真实车型。
3. 月数含字母、零月数、小数 SKU、零个 SKU 等非法输入显示错误；空值仍可计算。
4. 只填已确认外包 / 派遣时，用工贡献为 15 分，并触发选购偏好提示。五险一金未知仍在“仍未知的输入”中提示；计分已固定不表示缴费事实已核实。
5. 调整已计算输入时，旧结果隐藏；重新计算后才可保存，避免保存旧结果。
6. 保存超过 5 条后只保留最新 5 条；重开页面能载入；删除记录不清空当前输入。
7. 分享路径无查询参数，好友打开时不获取发送者的输入或结果。
8. 真机检查选择器、长文本、数字键盘、滚动到结果、分享入口和深色系统状态栏可读性。

源码语法与逻辑可在 Node 环境做离线验证；微信 WXML 编译与真机显示仍需微信开发者工具验收。
