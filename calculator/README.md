# 速成车计算器 0.1

根据用户输入计算五维购车关注指数；不依赖车型榜单，不显示未经校准的“速成车概率”。开发40%、全球化20%、正式召回15%、用工15%、基础SKU10%，用工取缴费与外包两项较高值。各项均允许不知道；未知保留0–100并传播到总分区间。

## 先体验网页版

直接打开 `web/index.html` 即可本地使用；静态托管时将整个 `web/` 目录作为站点根目录。没有登录、后端、外部脚本、字体请求或统计服务，计算在浏览器完成。

- 填写六个输入，输出指数或区间、五项贡献、已确定计分权重和补证优先项。
- 默认全部未知；虚拟示例不对应真实车型。
- 保存/读取/删除本机草稿，复制结果摘要，下载完整JSON记录。
- 来源笔记仅通过用户主动保存写入本机草稿；摘要不包含笔记，下载记录包含笔记。
- 用户输入并未经审核；不会自动改变公共车型数据库。公共资料仍须[附证据并经维护者校核](../CONTRIBUTING.md)。

所有维度贡献确定时可得到单个分值，即使某个用工子条件还未知。例如外包已知为100分，缴费未知无法再改变用工的max结果；这种情况下仍应核对未披露的子条件。资料完整度不等于准确率。

## 维护与验证

`shared/scoring.js` 是唯一计算核心，CommonJS和浏览器全局共用。改动后同步客户端副本：

```bash
python calculator/scripts/build_assets.py
node calculator/tests/scoring.test.cjs
python calculator/scripts/build_assets.py --check
```

网页UI显示到小数点后1位，JSON保留计算精度。JSON的 `evidenceStatus` 标注用户输入未核实，不能当作审核结论或厂家事实证明。发展月份必须大于0、SKU必须为正整数；空值为未知，0不等于未知。

阈值和权重与仓库指数保持一致。计算器额外允许用户声明“有充分依据确认无召回历史”，计R=100；“没有搜到”始终选择未知。这个选项只是一项自报输入，不会修改任何车型或车企的正式资料。
