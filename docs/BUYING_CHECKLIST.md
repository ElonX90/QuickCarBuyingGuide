# 下单前核查清单

先固定车款身份：品牌、具体年款、车系世代、动力、电池、驱动、座位、智驾硬件、生产企业。下单后核对合格证、生产日期和 VIN，防止销售描述与交付车不一致。

## 全球化和国内安全配置

- 海外对应车型在哪些国家已经正式销售？提供具体当地官网或监管/认证记录，不能只给海外车展照片或未来计划。
- 国内所选 SKU 与海外版相比，气囊、碰撞结构、应急机械开门、碰撞断电后逃生、eCall/自动事故求救是否一致？请提供国内配置表和车主手册的具体页码。
- 求救功能是否自动触发、发送位置和建立通话？后台服务、通信网络、信号丢失和断电时有哪些限制？无法核实时保留未知。
- 碰撞或辅助驾驶评价是否针对相同世代/配置？不同机构、规程年份和选装状态的星级不要直接等同。

## 研发和验证

- 本车型正式立项、整车项目启动、量产 SOP、正式上市、首批交付各是哪一天？分别提供证据。
- 哪些是全新平台、哪些继承已有平台？本年款新增硬件和软件有哪些，追加验证如何完成？
- 研发周期很短时，询问实体测试、跨季节测试与异常工况覆盖，而不只比较月份。
- 准备购买的智驾功能和服务是否已经交付可用？将未来 OTA 承诺与当前功能分别写入合同或交付说明。

## 召回和整改

- 按目标品牌和合格证上的生产企业分别检索正式召回公告；保留网址、公告日期、召回编号、生产批次和处置措施。
- 查询自己的 VIN 是否在召回范围、是否已完成。请保存官方查询和维修记录。
- 区分正常功能升级、服务活动和正式召回。OTA 是技术手段，不能单凭“免费升级”认定逃避召回，也不能认为已经更新就无需查 VIN。
- 若只能查到集团其他品牌记录，继续核对目标品牌及实际生产企业。未查到记录时属于待核，不是证明企业没有责任或从未存在缺陷。

## 五险一金和用工

- 核对真实用人单位和制造主体的关系；总部、工厂、销售公司、外包和劳务派遣不能混为一谈。
- 可核查证据应说明地区、人员范围、缴费工资口径、上下限、应缴与实缴到账、补缴及整改。依法足额不等于所有项目使用最大比例或突破缴费封顶。
- 招聘页写“有五险一金”、ESG 声称覆盖率 100%、财报合计福利金额，均不足以单独证明每位员工足额。
- 若有处罚、裁判或公司明确欠缴披露，核对主体、时间、人员范围和是否整改后再作结论，不把某个外包商或历史子公司的问题直接写成整个品牌现状。
- 只接受合法取得、必要且已去标识的信息；不要在公开 Issue 上传员工姓名、身份证、账户、完整工资单等个人材料。

## SKU 和配置复杂度

- 取得当前有价格、可下单的完整配置表，分清旧款库存、独立车系、不同世代和真正选装包。
- 分别计动力、电池/续航、驱动、座位与正式基础配置；不将颜色、轮毂、软件权益或金融方案全排列。
- 发现同名不同芯片、雷达、电池供应商或换代升级时，要求说明具体交付硬件及相应质量/维修支持。
- SKU 多时询问关键硬件组合的测试覆盖、售后配件和识别方式。SKU 数量本身不证明车不好；本指南默认 ≥9 标为较多，可按自己的偏好修改。

没有补齐的项目写成“待核查”。如果把上述四条设为严格购买条件，待核项目应继续查证或暂缓下单，不能用一个较低综合分替代这些要求。
