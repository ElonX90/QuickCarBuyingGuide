# 指数方向与计算示例

## 越大越可能是速成车吗

越大表示**越符合本指南定义的速成车关注特征、越需要审慎核查**。它不是经过统计校准的概率，不能把 80 分解释成“80% 是速成车”，也不能据此判断事故风险。全球化、召回和用工是本指南的治理/购车偏好信号，不能单独证明整车工程验证被压缩。

## 公式是什么

每项 0–100 分，综合：

`I = 0.40D + 0.20G + 0.15R + 0.15L + 0.10S`

`L = max(P, O)`，P 是五险一金欠缴情形，O 是外包/派遣用工情形。两条分别取证，任何一条已确认存在不符合偏好的情形，就不能由另一条抵消。

| 项目 | 权重 | 当前规则 |
|---|---:|---|
| D 开发跨度 | 40% | clamp(100×(36−月数)/18, 0, 100)。≤18个月100，≥36个月0，中间线性变化 |
| G 全球化 | 20% | 已核实国际产品家族0，海外衍生/硬件关系待匹配50，仅全球设计/发布80，官方中国专属100，其他未知 |
| R 召回历史 | 15% | 目标品牌有正式记录0，尚未取得充分证据为未知；已证实整改问题100 |
| L 用工保障 | 15% | P：范围完整且足额0，可靠证据确认欠缴且未整改100；O：完整范围确认无外包0，已确认存在外包/派遣100；未知单独保留，L取较高值 |
| S SKU | 10% | 1–3款0，4–5款30，6–8款60，9款以上100；不把车漆、金融等相乘 |

这些权重和 18/36 月阈值是可修改的编辑假设，不是行业质量合格线。平台复用、并行开发、全新平台和改款难度不同，当前公式没有充分校正这种差异。

## 缺数据怎么办

未知项保留 [0,100]，分别计算总分下界和上界，不填0、50或中点。分数区间是信息缺失下的计分边界，不是统计置信区间。两个区间重叠，无法据此给出确定次序。

**假设示例，非具体车型评价：**开发24个月时D≈66.7；G=0、R=0；SKU为4款时S=30；缴费与外包均未核实则L∈[0,100]。I≈[29.7,44.7]。之后若可靠资料确认有外包员工，则L=100且显示“不建议购买”，不是用其他低分将其抵消。

## 怎么越来越准

用来源及范围齐全的投稿补证，维护者核对原文和冲突资料，accepted 后复算；这可以缩小未知区间、纠正事实与提高完整性。若要将指数称为预测概率或验证“更准确”，还需要真实研发验证与质量结果的独立数据来评估，目前没有这样的校准。[完整方法](METHODOLOGY.md)、[贡献入口](../CONTRIBUTING.md)。
